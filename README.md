# Powerpoint Prompt for Android

Current release: **1.0.0**. Import PowerPoint speaker notes directly on the phone, keep bullets, and choose whether to add a blank line between bullet items.

Download the latest signed APK: [PPT-prompt.apk](https://github.com/brainok/powerpointer-prompt-android-release/releases/latest/download/PPT-prompt.apk)

[Release notes and older versions](https://github.com/brainok/powerpointer-prompt-android-release/releases)

Requires Android 8.0 or later. The APK is signed with the Powerpoint Prompt Android release key. SHA-256 checksums are attached to each release.
